🏎️ Projeto Fórmula 1

📌 Descrição

Este código cria e gerencia um banco de dados sobre Fórmula 1. Ele organiza informações em tabelas de países, equipes, pilotos e corridas, 
insere dados nessas tabelas, adiciona e atualiza valores de salários e realiza diversas consultas para extrair informações — como listar pilotos 
por país, calcular médias salariais e filtrar registros. É um exemplo prático de como estruturar, armazenar e consultar dados no MySQL.

🛠️ Tecnologia
- MySQL
